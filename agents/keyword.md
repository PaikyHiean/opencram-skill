# L2 子 agent（关键词索引）

**何时用**：Phase 8，当要生成 L2 关键词索引时。orchestrator 按单章派一个 Task 子 agent，
每个只领一章的 `work/distilled/l2/in_<k>.json`，控制上下文。

---

## 输入

子 agent 自己读盘（orchestrator 不传全文）：

```
work/distilled/l2/in_<k>.json
```

格式：
```json
{
  "chapter_index": 1,
  "chapter_title": "第1章 财产保险概论",
  "slide_count": 45,
  "slides": [
    {
      "anchor": "第一章财产保险概论.ppt#s5",
      "title": "近因原则",
      "paragraphs": [{"text": "近因原则：保险赔偿应基于直接有效地导致损失的原因", "level": 0}],
      "tables": []
    }
  ]
}
```

---

## 任务

从该章的幻灯片内容（标题 + 正文 + 表格，**不含备注**）中**识别并抽取**专业关键词/术语，按频率分级：

- **高**：章节核心概念——PPT 中反复出现、或在幻灯片标题/粗体定义语中出现，考试必背
- **中**：重要专业名词——有明确定义或对理解核心概念有支撑
- **低**：一般性术语——出现一次或仅作辅助说明

**抽取标准**：
- 只收专业/学科特定术语，通用词（"方法"、"体系"、"原则"本身太宽泛不收）
- 若 PPT 中有明确定义文字（"X 是指…"/"X 的含义为…"/"X，即…"），**原文逐字摘录**为 definition
- 若无定义，definition 留空字符串 ""，**禁止 AI 补充**
- 每章预期词条数：高频 5–15 个，中频 10–30 个，低频 0–20 个（视章节实际内容而定）

---

## 产出

写 `work/distilled/l2/out_<k>.json`：

```json
{
  "chapter_title": "第1章 财产保险概论",
  "terms": [
    {
      "term": "近因原则",
      "freq": "高",
      "definition": "保险赔偿应基于直接有效地导致损失发生的最近原因，而非远因",
      "anchors": ["第一章财产保险概论.ppt#s5", "第一章财产保险概论.ppt#s8"]
    },
    {
      "term": "保险利益",
      "freq": "高",
      "definition": "投保人对保险标的具有的法律认可的经济利益关系",
      "anchors": ["第一章财产保险概论.ppt#s3"]
    },
    {
      "term": "超额赔款再保险",
      "freq": "中",
      "definition": "",
      "anchors": ["第一章财产保险概论.ppt#s22"]
    }
  ]
}
```

**字段说明**：
- `term`：关键词/术语原文（来自 PPT，不改写；遇括号英文名只收中文简称）
- `freq`：`高` / `中` / `低`
- `definition`：PPT 原文中的定义（逐字或精简至一句话）；**无则留空字符串，禁止 AI 补充**
- `anchors`：该术语出现的幻灯片锚点（至少一个），**必须来自输入包的 anchor 字段**

---

## 边界（铁律）

1. **只收专业术语**：通用词（"分析"、"管理"、"制度"等单独出现时不收）不收。
2. **term 来自原文**：不改写术语名称；英文缩写保留括号外的中文名称。
3. **definition 禁止 AI 补充**：PPT 中无定义文字则 definition = ""，不臆造。
4. **锚点必须真实**：只用输入包里已有的 anchor，不虚构。
5. **只回简报给主控**：本章词条数（高/中/低各几个），不把全文 JSON 回给主控。

---

## 简报格式（回给 orchestrator）

```
=== L2 k=<k> 完成 ===
  章节：<chapter_title>
  词条：<N> 个（高 X / 中 Y / 低 Z）
  存疑/跳过：<描述（若有）>
  → work/distilled/l2/out_<k>.json
```
