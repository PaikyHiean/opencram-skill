# M 子 agent（思维导图·每章）

**何时用**：Phase 10，当要生成 M 思维导图时。orchestrator 按单章派一个 Task 子 agent，
每个只领一章的 `work/distilled/m/in_<k>.json`，控制上下文。

---

## 输入

子 agent 自己读盘（orchestrator 不传全文）：

```
work/distilled/m/in_<k>.json
```

格式：
```json
{
  "chapter_index": 1,
  "chapter_title": "第1章 财产保险概论",
  "section_count": 17,
  "sections": [
    {
      "label": "一、",
      "heading": "财产保险的概念与标的",
      "pointer": "源：第一章财产保险概论.ppt s.2–5",
      "points": ["以财产及有关利益为保险标的保险。", "有形财产（有实物形态）", "无形财产：责任、信用等"]
    }
  ]
}
```

---

## 任务

将该章的所有小节（通常 17–46 个）**按主题归纳整合**为 **6–12 个分支**，每个分支代表一个知识主题群。

**归纳原则**：
- 把内容相近的小节合并为一个分支（如"保险价值"+"保险金额"+"超额/不足额保险"→ 分支"保险价值与金额"）
- 分支标题：**6–12 字**，名词性短语，能概括该分支所有内容
- 每个分支下列出 **3–6 个节点**（nodes）：
  - 节点 = 该主题下最重要的知识要点，精炼为 **12–25 字**的短句
  - 优先选考试重点（定义、条件、数字、流程名称）
  - 来自 PPT 原文，可精简但不改写，**禁止 AI 补充**
- 每章分支总数 6–12 个，节点总数 30–60 个

---

## 产出

写 `work/distilled/m/out_<k>.json`：

```json
{
  "chapter_index": 1,
  "chapter_title": "第1章 财产保险概论",
  "branches": [
    {
      "title": "概念与保险标的",
      "nodes": [
        "财产险以财产及有关利益为标的",
        "标的分有形财产与无形财产",
        "可保利益须合法、确定、可用货币估量"
      ]
    },
    {
      "title": "保险四项基本原则",
      "nodes": [
        "近因原则：以直接有效原因定损",
        "损失补偿：赔款不超过实际损失",
        "代位求偿：赔付后保险人取得追偿权",
        "可保利益：投保人须对标的有合法利益"
      ]
    }
  ]
}
```

**字段说明**：
- `title`：分支标题，6–12 字名词短语
- `nodes`：该分支的核心知识点列表，每条 12–25 字，来自 PPT 原文（可精简）

---

## 边界（铁律）

1. **主题归纳为主**：不要逐节照搬，要真正做到"合并同类、提炼核心"
2. **节点来自原文**：只精简，不改写，不补充 AI 内容
3. **分支数量控制**：6–12 个（少于 6 说明归纳过粗，超过 12 说明拆得太碎）
4. **节点长度合理**：12–25 字（太短失去信息，太长占空间）
5. **只回简报**：不把全文 JSON 回给主控

---

## 简报格式（回给 orchestrator）

```
=== M k=<k> 完成 ===
  章节：<chapter_title>
  分支：<N> 个，节点共 <M> 条
  → work/distilled/m/out_<k>.json
```
